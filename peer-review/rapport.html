# On formatte les nombres pour passer de "10000000" à "10M"
format_number <- function(n) {
  
  if (n >= 1e6) { 
    paste0(round(n / 1e6, 1), "M") # Si le nombre est au moins 1 million, on le remplace par "...M"
    
  } else if (n >= 1e3) {
    paste0(round(n / 1e3, 1), "K") # Si le nombre est au moins 1 millier, on le remplace par "...K"
    
  } else {
    as.character(n)
  }
}

# On formatte les intervalles d'acheteurs pour passer de "10000000 - 20000000" à "10M - 20M"
format_range <- function(x) {
  
  sapply(strsplit(x, " - "), function(parts) { # Pour chaque intervalle, on divise la chaîne de caractère en 2 parties
    
    parts <- as.numeric(parts) # On convertit ces 2 parties en nombre
    
    paste0( # On créée une nouvelle chaîne contenant
      format_number(parts[1]), # Le nombre bas de la fourchette formatté avec la fonction "format_number",
      " - ", # La chaîne de caractère permettant de séparer les deux extrémités de la fourchette
      format_number(parts[2]) # Et le nombre haut de la fourchette formatté avec la fonction "format_number"
    )
  })
}

6ème facteur : le studio de développement

Certains jeux tiennent leur réputation de leur studio de développement, comme les jeux de Riot Games qui ont suivi League of Legends ou ceux étant paru après OverWatch. Le studio de développement peut donc être un facteur d’impact sur les ventes d’un jeu, ce qui révèle la question suivante :

Est-ce que le studio de développement impacte la vente d’un jeu ?

Etant donné qu’il existe des centaines de studios de développement et par souci de clareté, nous avons décidé de n’alayser que les plus grands studios, c’est-à-dire ceux qui ont les jeux les plus vendus. Nous allons donc voir quels studios ont développé les 10 jeux de la fourchette 50-100 millios d’acheteurs, et y ajouter les développeurs de Dota 2 et Counter Strike 2.

Afin de poursuivre notre analyse du dataset de jeux vidéos, nous nous efforcerons d’essayer de répondre à la question suivante :

Quels sont les jeux les plus appréciés ?

En parcourant les différentes variables du jeu de données, la mise en relation des colonnes price désignant le prix d’un jeu et pct_pos_total correspondant à la note attribuée au jeu semblait intéressante. En effet, on s’attendrait que plus on met de l’argent dans un jeu, mieux celui-ci devrait être. Cependant, il est compliqué de réellement de définir ce qu’est la qualité d’un jeu, ainsi nous nous baserons sur l’appréciation qu’ont les joueurs sur un jeu pour définir si le jeu est bien ou non.
