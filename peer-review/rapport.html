Y a-t-il des facteurs qui impactent les ventes d’un jeu ?

Pour répondre à notre problématique principale, nous allons utiliser la variable estimated_owners. Cette variable est une chaîne de caractère représentant une fourchette d’entiers. Actuellement, on peut y voir “100000 - 200000” ou “200000000 - 500000000”, ce qui n’est pas très lisible sur une visualisation. Il faut donc formater ces chaînes de caractère, et les mettre dans le bon ordre, pour avoir sur nos graphiques les fourchettes de la plus petite à la plus grande.

# On formate les nombres pour passer de "10000000" à "10M"
format_number <- function(n) {
  if (n >= 1e6) { 
    paste0(round(n / 1e6, 1), "M") # Si le nombre est au moins 1 million, on le remplace par "...M"
    
  } else if (n >= 1e3) {
    paste0(round(n / 1e3, 1), "K") # Si le nombre est au moins 1 millier, on le remplace par "...K"
    
  } else {
    as.character(n)
  }
}

# On formate les intervalles d'acheteurs pour passer de "10000000 - 20000000" à "10M - 20M"
format_range <- function(x) {
  
  sapply(strsplit(x, " - "), function(parts) { # Pour chaque intervalle, on divise la chaîne de caractère en 2 parties
    
    parts <- as.numeric(parts) # On convertit ces 2 parties en nombre
    
    paste0( # On crée une nouvelle chaîne contenant :
      format_number(parts[1]), # Le nombre bas de la fourchette formaté avec la fonction "format_number",
      " - ", # La chaîne de caractère permettant de séparer les deux extrémités de la fourchette
      format_number(parts[2]) # Et le nombre haut de la fourchette formaté avec la fonction "format_number"
    )
  })
}

1er facteur : le prix

L’un des premiers facteurs qui nous vient à l’esprit est le prix, nous allons donc observer les variables price et estimated_owners pour répondre à la question suivante :

Y a-t-il une corrélation entre le prix d’un jeu et ses ventes ?

Etant donné que nous cherchons à montrer une évolution de la proportion du prix en fonction du nombre d’acheteurs, un line chart est une visualisation adaptée.

# On copie notre jeu pour ne pas l'altérer
data_date <- jeu_allege

# On ajoute une variable à data, contenant les fourchettes associées au prix de chaque jeu
data_date$prix_cat <- cut(data_date$price, # On découpe les prix en intervalles
  breaks = c(-0.01, seq(0, 30, 5), Inf), # Ces intervalles vont de -0.01 à Inf, de 5 en 5 en s'arrêtant à 30, pour avoir les jeux gratuits : ]-0.01-0] et payants : ]0-5] etc... jusque ]30-Inf[
  labels = c("Gratuit", paste0(seq(0, 25, 5), "–", seq(5, 30, 5), "$"), "Plus de 30$"), # On donne un nom à chaque intervalle
)

# On crée l'ordre croissant des fourchettes de prix pour avoir un graphique lisible
ordre_prix <- c("Gratuit", paste0(seq(0, 25, 5), "–", seq(5, 30, 5), "$"), "Plus de 30$")

# On applique cet ordre à notre jeu
data_date$prix_cat <- factor(data_date$prix_cat, levels = rev(ordre_prix))

# On calcule la répartition des jeux selon leur catégorie de prix et leur nombre d'acheteurs
repartition_prix <- data_date %>%
  count(fourchettes_affichage, prix_cat) %>% # On compte le nombre de jeux pour chaque combinaison fourchette d’acheteurs - catégorie de prix
  group_by(fourchettes_affichage) %>% # On regroupe ce décompte par fourchette pour calculer les proportions
  mutate(prop = n / sum(n)) %>% # On ajoute la variable prop, dans laquelle on stocke la proportion de chaque catégorie de prix par fourchette
  ungroup() # On retire la structure groupée

# On crée notre visualisation
ggplot(repartition_prix, aes(x = fourchettes_affichage, y = prop, group = prix_cat, color = prix_cat)) +
  
  geom_line() + # On fait un line chart pour montrer l'évolution de la proportion
  geom_point()  + # On met les points pour mieux voir où s'arrête l'évolution

  labs(
    title = "Répartition des prix selon le nombre d'acheteurs",
    x = "Nombre d'acheteurs",
    y = "Proportion de jeux",
    color = "Prix"
  ) + # On ajoute titre, nom des axes et légende
  
  theme(axis.text.x = element_text(angle = 45, hjust = 1)) # On incline l'axe des x pour pouvoir lire les fourchettes

Grâce à cette visualisation, nous pouvons observer plusieurs choses, notamment que la proportion de jeux gratuits augmentent avec les nombre d’acheteurs, même en oubliant les 2 dernières fourchettes, qui ne contiennent qu’un jeu chacune. Cela paraît logique puisque les jeux gratuits sont les plus accessibles.

Fait plus étonnant, le nombre de jeux de plus de 30$ augmente également avec le nombre d’acheteurs. Cela semble contre-intuitif, mais une très bonne réputation, une boîte de production célèbre ou des critiques très positives sur le graphisme, le gameplay ou les personages peuvent justifer et faire oublier le prix “élevé” d’un jeu.

Nous pouvons également constater que la gratuité ne fait pas la vente, puisque plus de près de 87% des jeux invendus sont gratuits. Cela peut être dû à une mauvais réputation, un manque de publicité ou des images peu attrayantes.

Nous pouvons également voir que la variété des prix diminue avec le nombre d’acheteurs. Plus les tranches sont élevées, moins il y a de fourchettes de prix différentes. Nous ne voyons pas d’explication à ce phénomène.

Toutes ces observatios nous permette de supposer que le prix a certes un impact sur les ventes, mais d’autres facteurs entrent sûrement en jeu lors de l’achat d’un jeu vidéo.

2ème facteur : la limite d’âge

Lorsque l’on achète un jeu, il n’est pas rare qu’une limite d’âge soit affichée, que ce soit pour prévenir de la vulgarité, de la violence ou de la peur que peut provoquer un jeu, le fameux PEGI. Cette limite d’âge peut représenter un frein lors de l’achat d’un jeu, du moins c’est ce que nous aimerions savoir, grâce à la visualisation qui suit, qui nous permettrait de répondre à la question suivante :

La limite d’âge d’un jeu a-t-elle un impact sur ses ventes ?

Pour y répondre, nous allons utiliser les variables estimated_owners et age. Etant donné qu’il y a beaucoup de limites d’âge, un line chart serait illisible. Nous allons donc changer de visualisation. Un bar chart pourrait être utilisé, mais on ne verrait pas bien toutes les proportions. Une heat map nous paraît donc être le meilleur choix pour concilier grande masse d’informations et lisibilité.

# On copie notre jeu pour ne pas l'altérer
data_age <- jeu_allege

# On trie les jeux dans l'ordre de la limite d'âge la plus basse à la plus haute
data_age$age_cat <- factor(data_age$required_age, levels = sort(unique(data_age$required_age)))

# On calcule la répartition des jeux selon leur âge limite et leur nombre d'acheteurs
repartition_age <- data_age %>% 
  count(age_cat, fourchettes_affichage) %>% # On compte le nombre de jeux pour chaque combinaison fourchette d’acheteurs - âge limite
  group_by(fourchettes_affichage) %>% # On regroupe ce décompte par fourchette pour calculer les proportions
  mutate(prop = n / sum(n)) %>% # On ajoute la variable prop, dans laquelle on stocke la proportion de chaque âge limite par fourchette
  ungroup() # On retire la structure groupée

ggplot(repartition_age, aes(x = fourchettes_affichage, y = age_cat, fill = prop)) +

  labs(
    title = "Répartition des limites d'âge selon le nombre d'acheteurs",

    y = "Âge limite",
    fill = "Proportion"

Sur ce graphique, on peut voir qu’il y a au moins un jeu pour lequel la limite d’âge est égale à -1. Une erreur a pu se glisser lors du nettoyage de notre jeu de données, mais dont la proportion est si faible qu’elle n’empêche pas l’analyse du reste des informations.

Nous constatons avant tout que la grande majorité des jeux n’ont pas de limite d’âge (ligne quasiment entièrement jaune sur l’axe 0).

De plus, il semblerait que plus la fourchette d’acheteurs augmente, plus la proportion de jeux avec une limite d’âge élevée augmente.

Cette constatation va à l’encontre de notre hypothèse, puisque nous pensions qu’un jeu avec une limite d’âge basse serait accessible à un plus grand nombre de joueurs et donc plus acheté. Mais ici, on voit qu’à partir de la fourchette 2-5 millions d’acheteurs, près d’un quart des jeux ont une limite d’âge supérieure ou égale à 17 ans. Cela pourrait s’expliquer par le fait que beaucoup de jeux populaires ont cette limite d’âge, comme Grand Theft Auto V, Call of Duty ou Red Dead Redemption 2.

Enfin, nous pouvons voir que la fourchette 50-100 millions d’acheteurs n’a que 50% de ses jeux qui n’ont pas de limite d’âge, ce qui est normal, puisque, comme nous l’avons vu dans le tableau des 12 jeux les plus vendus, la moitié de ceux composant cette fourchette sont des jeux violents, qui ont donc une limite d’âge élevée : GTA V, HELLDIVERS 2, Call of Duty, Lost Arc. Le jeu avec une limite d’âge de 13 ans est Black Myth: Wukong. Un des jeux de la fourchette d’acheteurs 50-100 millions d’acheteurs semble d’ailleurs avoir changé de limite d’âge entre le moment où le dataset a été publié et aujourd’hui, puisque PUBG: Battlefields est annoncé sans limite d’âge dans notre dataset, mais sur Steam, il est restraint aux plus de 16 ans. 4ème facteur : la date de publication

Si nous voulons observer l’impact de différents facteurs sur les ventes d’un jeu, nous pouvons prendre les dates de publication. En effet, il serait intéressant de voir si les nombre de ventes d’un jeu varie selon le mois de publication. Nous allons donc mettre en relation les variables release_date et estimated_owners pour répondre à la question :

Y a-t-il une corrélation entre le mois de publication d’un jeu et ses ventes ?

Le but ici est de voir si, par exemple, plus de monde achète un jeu paru en novembre, juste avant les fêtes, ou en juillet, au début des grandes vacances.

Etant donné qu’on veut voir une évolution au cours du temps, un line chart semble être la visualisation la plus appropriée.

# On copie notre jeu pour ne pas l'altérer
data_date <- jeu_allege

# On calcule la répartition des jeux selon leur mois de publication et leur nombre d'acheteurs
repartition_date <- data_date %>%

7ème facteur : le(s) genre(s)

Il arrive souvent que l’on recherche un jeu par genre : un jeu d’action, d’aventure, de course, de simulation, etc… On pourrait donc supposer que certains genres sont plus populaires que d’autres, et sont donc plus achetés. C’est pour cela que nous allons répondre à la question suivante, grâce aux variables estimated_owners et genres :

Est-ce que le(s) genre(s) impacte la vente d’un jeu ?

Pour vérifier cela, nous allons utiliser une heat map, pour les mêmes raisons que la limite d’âge. En effet, le grand nombre de genres existant rendraient illisible un bar chart ou un line chart.

Avant de commencer à interpréter cette visualisation, il est important de noter qu’un jeu peut avoir plusieurs genres. Donc, lorsque nous dirons “jeu indé” ou “jeu d’aventure”, nous vondrons dire “jeu qui comporte le genre Inde” ou “jeu qui comporte le genre Adventure”.

Cette visualisation nous permet d’obtenir plusieurs informations.

La première est que les jeux indés représentent près d’un quart des jeux des 5 premières fourchettes, une fois les invendus exclus, ce qui signifie qu’environ 25 % des jeux ayant entre 1 et 500 000 acheteurs sont des jeux indés.

La deuxième est que les jeux d’aventure représentent près de 15 % de tous les jeux, il s’agit du 2ème genre le plus représenté, après le genre Action, qui semble définir plus de 20 % de tous les jeux.

En ce qui concerne l’évolution des proportions au fil des fourchettes, on peut remarquer que la proportion des jeux Massively Multiplayer augmente avec le nombre d’acheteurs, tout comme les jeux d’action. Le genre RPG augmente aussi, mais plus légèrement. A l’inverse, la proportion de jeux indés et casual baisse avec le nombre de joueurs, tandis que le genre Adventure semble stagner.

Toutes ces informations nous font dire que le genre est corrélé au nombre d’acheteurs, et que certains genres populaires poussent les joueurs à acheter les jeux associés. Nous verrons plus tard dans le rapport si cela peut également être lié au nombre d’avis positifs laissés.

Détaillons à présent le paradoxe entre l’âge limite et le genre. Comme nous l’avons vu précédemment, à partir de 2 millions d’acheteurs et jusque 100 millions d’acheteurs, l’âge limite est plus souvent entre 16 et 18 ans que pour les autres fourchettes. Toutefois, lorsque l’on regarde les genres des fourchettes composant cet intervalle, on constate qu’aucun jeu ne comporte Violent, Sexual Content, Nudity ou Gore. Pourtant, ce sont ces critères qui sont utilisés pour donner une limite d’âge à un jeu. Après vérification sur la plateforme Steam, nous avons pu constater qu’en effet, ces jeux n’étaient pas catégorisés comme violents ou gores, ce n’était pas une erreur de dataset. On en vient donc à se pose une question : est-ce que les jeux populaires omettent volontairement de s’inscrire dans ces genres pour booster leurs ventes ? Pour éviter de trop inquiéter les joueurs, puisqu’il y a déjà une limite d’âge élevée ? Ou parce qu’on se dit justement que la limite d’âge suffit, et qu’il n’y a pas besoin d’expliciter le genre ?

Cette omission volontaire pourrait expliquer les chiffres des 2 visualisations concernées (âge limite et genre), et tendrait à confirmer que les genres influencent les ventes, certains en bien, Action, Adventure et Free To Play, et d’autres en mal, comme Violent, Nudity ou Sexual Content puisque Steam retire ces genres des jeux les plus achetés.

Conclusion

Grâce à toutes ces visualisations, nous avons pu constater que plusieurs facteurs peuvent avoir un effet sur les ventes d’un jeu. Les genres semblent avoir le plus d’impact, mais le prix et les langues supportées semblent également jouer un rôle important lors de l’achat d’un jeu.

A noter que, sur certaines visualisations de cette section, la fourchette 50 millions - 100 millions d’acheteurs présente une différence avec les autres fourchettes : elle suit la tendance inverse des fourchettes précédentes, notamment pour les facteurs langues supportées, système d’exploitation et âge limite. Malgré nos recherches, nous n’avons pas trouvé comment expliquer ce phénomène.

Pour poursuivre notre analyse du dataset de jeux vidéos, nous adopterons un autre angle afin de répondre à la question suivante :

Quels facteurs contribuent à l’appréciation d’un jeu ?

Tout d’abord, en parcourant les différentes variables du jeu de données, la mise en relation des colonnes price désignant le prix d’un jeu et pct_pos_total correspondant à la note attribuée au jeu semblait intéressante. En effet, on s’attendrait que plus on met de l’argent dans un jeu, mieux celui-ci devrait être. Cependant, il est compliqué de réellement de définir ce qu’est la qualité d’un jeu, ainsi nous nous baserons sur l’appréciation qu’ont les joueurs sur un jeu pour définir si le jeu est bien ou non.

D’où la question suivante :

Est-ce que les jeux les plus appréciés sont ceux pour lesquels les joueurs paient le plus ?

Tout d’abord, pour répondre à la question, nous avons exploré le jeu de données pour voir s’il était cohérent de représenter dans son entièreté un graphique mettant en relation prix (price) et avis positif des jeux (pct_pos_total). Après exploration des données, on se rend compte qu’il y a très peu de jeux dont le prix est supérieur à 70 euros, ainsi on décide d’écarter ces jeux pour avoir une meilleure visibilité de la tranche la plus représentée (jeux allant de la gratuité jusqu’à 70 euros). Pour votre curiosité, les quelques jeux se situant aux alentours de 200 euros sont des jeux de puzzle en 3D et sont majoritairement mal notés donc on peut penser qu’ils ne valent pas leur prix.

Ainsi, on ne peut pas vraiment dire qu’il y a de lien entre l’appréciation d’un jeu et son prix. Cependant, ce graphique ne nous indique pas à quel point la note d’un jeu sera fiable ou non car on ne connait pas la distribution du nombre de reviews pour chaque tranche de prix. En effet, une évaluation positive a peu d’intérêt si peu d’utilisateurs ont participé à celle-ci. D’où la question suivante :

Quel est le nombre de reviews moyen qui ont été attribuées pour chaque tranche de prix ?

Pour répondre à cette question, on souhaite mettre en relation le nombre de reviews de jeux (num_reviews_total) avec des tranches de prix allant de 5 à 5 (price). On constate que plus le jeu est cher, plus on a d’avis et donc de notes à propos de celui-ci. Ainsi on peut imaginer que les notes qui sont attribuées à un jeu à prix élevé sont plus fiables (car plus nombreuses) que pour un jeu peu coûteux voire gratuit.

Comment le nombre de jeux qui sort chaque année évolue avec le temps pour chaque genre ? Comment évolue l’appréciation des jeux avec le temps pour chaque genre ?

Tout d’abord, si on sélectionne les genres les plus appréciés : Indie, Casual, Adventure, on se rend compte qu’il suivent tous la même tendance : de plus en plus de jeux chaque année et une appréciation de plus en plus élevée. Cependant, sélectionnons les genres pour lesquels les joueurs passent le plus de temps dessus : Casual, Adventure, Massively Multiplayer et Simulation. On se rend compte que le nombre de jeux par année augmente au fil du temps pour chacun des genres sélectionnés mais on constate également que le nombre de jeux du genre “Massively Multiplayer” n’augmente très peu comparé aux autres genres. Ainsi, quand on voit que l’appréciation des jeux de ce genre est basse par rapport aux autres genres, on peut se dire que c’est parce qu’il y a moins de jeux dans la catégorie et que ces jeux sont en particulier moins bien notés. Ensuite, sélectionnons les pires genres : Nudity, Gore, Violent. On constate que ces jeux ne sont pas très nombreux chaque année et que les données s’arrêtent au maximum en 2021. On peut ainsi remettre en question l’utilisation de ces genres puisque très peu de jeux adoptent ces genres tandis qu’en réalité, nous pensons qu’il existe bien plus de jeux violents par exemple (ou alors problème du dataset ?). Enfin, si on essaie de comparer tous les genres qu’on a cité avant (dans la question mise en relation du temps moyen passé dans les jeux avec appréciation des jeux), on se rend compte que globalement, la tendance veut que le nombre de jeux augmente chaque année et il n’y a pas de surprise à ce niveau là. De plus, on remarque que l’appréciation des jeux augmente avec le temps malgré une baisse dans les années 2014-2017. En effet, on constate que ce qui a plombé l’appréciation des jeux dans les années 2014-2015 sont vraiment les jeux en Early Access ce qui confirme en partie la théorie sur les jeux sortis en version beta faisant baisser l’appréciation globale de ces années-là. On notera tout de même que malgré le peu de jeux de sports sortis dans ces années là, l’appréciation de ces jeux change de la tendance globale : là où tous les jeux de ces années sont moins appréciés, les jeux de sports se démarquent en ayant une appréciation qui augmente. Peut-être qu’on peut imaginer que les jeux de ces années là ont sorti des nouvelles mécaniques rendant leurs jeux meilleurs (pour avoir vu le détail, les jeux de ces années sont majoritairement des jeux Trackmania dont le principe est la course de voitures).

Conclusion

L’ensemble de ces visualisations permettent de dire que globalement, pour jouer à un bon jeu, il n’est pas forcément nécessaire de payer cher. De plus, les jeux sur lesquels les joueurs passent le plus de temps sont globalement les plus appréciés (si on met de côté les jeux “Massive Multiplayer” qui constituent une exception). Les genres les plus appréciés sont d’ailleurs Adventure, Casual, Indie car on peut imaginer qu’ils sont adaptés à tout public. Les moins appréciés sont Gore, Violent, Nudity et ce, parce qu’on peut imaginer qu’ils peuvent choquer leurs utilisateurs. Enfin, plus un jeu est récent, plus celui-ci est apprécié donc on peut imaginer que les jeux récents sont de meilleure qualité ou que les utilisateurs sont plus généreux en terme de notes.
